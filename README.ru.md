# unattend-gen

[English](README.md) | Русский | [简体中文](README.zh-CN.md) | [Español](README.es.md) | [हिन्दी](README.hi.md)

CLI- и TUI-инструмент, который генерирует файлы ответов `autounattend.xml`
для автоматической установки Windows 10/11. Это терминальный аналог
[schneegans.de/windows/unattend-generator](https://schneegans.de/windows/unattend-generator/):
язык и редакция, имя компьютера и локальные аккаунты, телеметрия и системные
твики, Wi-Fi. Настраиваете один раз и используете результат при каждой
установке.

Профиль — это обычный JSON-файл со всеми настройками. CLI и TUI читают и
пишут один и тот же формат профиля и строят XML одним и тем же кодом, поэтому
один и тот же профиль всегда даёт один и тот же файл ответов, как бы он ни был
заполнен.

**Полная документация:** [docs/USAGE.ru.md](docs/USAGE.ru.md)
([English](docs/USAGE.md)) — все команды CLI, описание экранов TUI и справочник
по каждому полю профиля.

## Возможности

- Язык, локаль, раскладка клавиатуры, редакция Windows и ключ продукта
  (включая ключи, хранящиеся в прошивке BIOS/UEFI, и отдельный ключ только для
  активации), архитектура процессора (x64/x86/ARM64)
- Имя компьютера, часовой пояс и до 5 локальных аккаунтов, управление
  автовходом
- Экспресс-настройки (телеметрия) и 33 системных твика (Windows Update, UAC,
  обход аппаратных требований Windows 11, SmartScreen, быстрый запуск,
  восстановление системы, длинные пути, удалённый рабочий стол, очистка
  junction-точек, защита от перезагрузки после обновлений, ужесточение ACL и
  другое)
- Экраны OOBE (EULA, регистрация OEM, настройка сети) скрываются автоматически,
  если в профиле достаточно настроек для установки без них; отдельный флаг
  позволяет не требовать учётную запись Microsoft (best-effort: Microsoft не
  раз закрывала этот обход, поэтому он работает не на каждой сборке Windows)
- Профиль Wi-Fi (SSID, WPA2/WPA3/открытая сеть, скрытые сети)
- Удаление предустановленных приложений (Xbox, Teams, Solitaire, OneDrive,
  Microsoft Store, Windows Terminal и ещё 36), компонентов Windows (Internet
  Explorer, WordPad, клиент OpenSSH, Windows Hello и другие) и устаревших
  необязательных компонентов (Recall, клиент удалённого рабочего стола,
  Media Features)
- Пользовательские скрипты (.cmd/.ps1/.reg/.vbs) в четырёх точках: System (до
  создания аккаунтов), DefaultUser (для каждого аккаунта, включая будущие),
  FirstLogon (один раз) и UserOnce (один раз для каждого аккаунта)
- Политика срока действия паролей и блокировки аккаунтов
- Твики проводника (скрытые и системные файлы, расширения файлов, классическое
  контекстное меню, подсказки, папка по умолчанию, «Снять задачу» на панели
  задач) — применяются ко всем аккаунтам, включая будущие
- Персонализация (светлая/тёмная тема, акцентный цвет, прозрачность, однотонные
  обои) — тот же механизм для всех аккаунтов
- Пресеты визуальных эффектов (лучший вид, лучшая производительность или 17
  отдельных переключателей) для всех будущих аккаунтов
- Меню «Пуск» и панель задач: режим поля поиска, выравнивание по левому краю
  (Win11), скрытие кнопки «Представление задач», показ всех значков в трее,
  отключение виджетов и результатов Bing, закрепления «Пуска» (JSON для Win11)
  и плитки (XML для Win10), закреплённые значки панели задач (пустой набор или
  свой XML раскладки)
- Залипание клавиш (по умолчанию/отключено/своё) и начальное состояние и
  поведение Caps/Num/Scroll Lock — для будущих аккаунтов, текущей сессии и
  экрана блокировки
- Видимость значков рабочего стола (Этот компьютер, Корзина и ещё 11) и папки,
  закреплённые в меню «Пуск» (Win11) — для всех будущих аккаунтов
- Автоустановка гостевых инструментов виртуальных машин (VirtualBox, VMware,
  VirtIO, Parallels) и сырой XML политики AppLocker
- Динамическое имя компьютера через PowerShell-скрипт, обфускация (Base64)
  паролей аккаунтов в XML, автозапуск экранного диктора, необязательное
  сохранение файла ответов после установки, сырой XML экспортированного
  профиля WLAN и глобальный переключатель, скрывающий все окна PowerShell во
  время установки
- Два встроенных пресета (`minimal`, `single-user`) в качестве отправной точки
- Интерактивный TUI для пошагового заполнения профиля с живым предпросмотром
  XML перед сохранением
- Один статический бинарник: без сервера, без сетевых вызовов, без
  конфигурации, кроме JSON-файла профиля

Разметка диска намеренно не поддерживается: Windows Setup, как и при обычной
ручной установке, всегда спрашивает, куда устанавливать систему.

## Установка

Нужен Go 1.23+.

```sh
git clone https://github.com/FlexEbat/unattend-gen.git
cd unattend-gen
go build -o unattend-gen ./cmd/unattend-gen
```

Кросс-компиляция под другую ОС через `GOOS`/`GOARCH`:

```sh
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -o unattend-gen.exe ./cmd/unattend-gen
```

## Использование

Создайте профиль, проверьте его и превратите в файл ответов:

```sh
unattend-gen profile init demo                    # demo.json со значениями по умолчанию
unattend-gen profile init demo --preset minimal    # или начните с пресета
unattend-gen profile list                          # список профилей в ./profiles
unattend-gen validate demo.json                     # код возврата 0 или 1
unattend-gen generate demo.json                     # пишет autounattend.xml рядом с профилем
unattend-gen generate demo.json -o out.xml          # или по выбранному пути
```

Или заполните профиль интерактивно:

```sh
unattend-gen tui               # с нуля
unattend-gen tui demo.json     # из существующего профиля
```

Положите получившийся `autounattend.xml` в корень загрузочной USB-флешки с
Windows (или подключите как виртуальную дискету/CD в виртуальной машине), и
Windows Setup подхватит его автоматически.

## Структура проекта

```text
cmd/unattend-gen/     точка входа
internal/profile/     схема Profile, загрузка/сохранение JSON, валидация
internal/xmlgen/      сборщик autounattend.xml и его компоненты
internal/cli/         команды cobra: profile, validate, generate, tui
internal/tui/         приложение bubbletea: экраны и общие виджеты
presets/              встроенные пресеты профилей, вшиты в бинарник
```
